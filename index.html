Current curriculum

Five learning objectives

This is more than a rack of hardware. It's a place to practice the skills that make real systems dependable.

01

Orchestration

Operate Kubernetes with confidence

Build, upgrade, and troubleshoot a highly available K3s cluster while learning how etcd, scheduling, reconciliation, and safe node maintenance fit together.

  • K3s
  • Rancher
  • etcd
  • Ansible

02

Networking

Understand how traffic really moves

Explore eBPF networking, ingress, TLS, tunnels, service discovery, and policy—not just until packets flow, but until the path makes sense.

  • Cilium
  • Traefik
  • Cloudflare
03

Resilience

Make recovery a practiced skill

Protect persistent data, verify every backup, rehearse restoration, and design for the day a disk, node, or entire cluster stops cooperating.

  • Longhorn
  • Snapshots
  • DR
  • S3
04

Observability

Turn signals into understanding

Connect metrics, logs, dashboards, and alerts so failures leave evidence—and capacity decisions are based on data instead of guesses.

  • Prometheus
  • Grafana
  • Loki
  • Alloy
05

Automation & security

Build repeatable, safer operations

Treat infrastructure as code, gate changes through pull requests, reduce configuration drift, patch vulnerabilities, and automate the checks worth repeating.

  • GitHub Actions
  • Fleet
  • SOPS
  • Dependabot
